# Switchboard 3D assets

## Models

| File | Description | License |
|------|-------------|---------|
| `rcbo.glb` | 1-pole DIN RCBO shell — stepped MAX9-inspired form, deep terminals, switch cavity, yellow DIN clip (static; rocker/TEST overlaid at runtime) | Original work for this project |
| `main-switch.glb` | Main isolator shell (same language, red accents) | Original work for this project |

Generic DIN-style forms inspired by common Australian residential RCBOs. **No trademarked logos or brand face art.** Blue accents are intentional product styling.

Regenerate with:

```bash
npm run generate:switchboard-models
```
